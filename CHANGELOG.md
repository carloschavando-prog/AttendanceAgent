# Changelog — Attendance Dashboard

A running log of notable changes to the On Par Bar attendance dashboard.

## 2026-07-08 — Added "Acknowledged" column

Added an **Acknowledged** column to the attendance dashboard so we can now see at a
glance whether each staff member has actually signed their disciplinary
documentation — not just what level they're on. Green (e.g. `2/2`) means everything's
acknowledged; amber (e.g. `0/2`) means a write-up is still outstanding.

This was **Samantha's idea** — she pointed out that we could see someone was on, say,
a verbal, but had no way to know if they'd acknowledged it. Great catch, Sam; it
closes a real gap for staffing. — Carlos
